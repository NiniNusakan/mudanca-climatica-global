# Calculadora de CO₂

## Introdução:
Este é um site feito para que possamos calcular a quantidade de CO₂ que é gerada durante as atividades diárias dos usuários.
## Funções:
- Página de login para registrar os cálculos antigos
- Questionário do seu cotidiano
- Calculadora do CO₂ baseada nos resultados das resposta
- Pastinha que registra seu dia a dia
